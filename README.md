## `whoami`

I'm **smiledemic**, an independent developer exploring browser-based games, interactive web experiences, game revivals, and creative software projects.

I enjoy experimenting with existing games, bringing experiences to the browser, troubleshooting technical challenges, and building things that people can actually explore and use.

- 🎮 **Game development:** Browser games, game revivals, and gameplay experiments.
- 🌐 **Web development:** Websites, interactive interfaces, and web-hosted projects.
- 🛠️ **Problem solving:** Debugging, reverse engineering, and tackling unfinished technical challenges.
- 🤝 **Open source:** Sharing projects and welcoming collaboration through GitHub.
- 🚀 **Long-term goal:** Keep expanding my projects, improving my skills, and building a recognizable developer presence through Ankom Studios.
